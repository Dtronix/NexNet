## Goal
Add a symbol-free, equatable, language-neutral IR, projected from the existing `TypeShape` graph and `InvocationInterfaceData`. The C# output must stay **byte-for-byte unchanged**. Background: report §3.1.

## Owns
- `src/NexNet.Generator/Ir/**` (new)
- `src/NexNet.Generator/Serialization/ShapeBuilder.cs`: add enum member names, nullability on member types, literal initializers. These must not affect the hash.
- `src/NexNet.Generator/Serialization/TypeShape.cs`: additive fields only.
- `src/NexNet.Generator.Tests/Ir/**` (new)
- `docs/internals/nexnet-ir.md` (new; the schema doc)

`NexusGenerator.cs` is **not** owned. G02 wires the IR into the pipeline. Here, expose a pure function `IrBuilder.Build(...)` that is testable from unit tests.

## IR shape

```
NexusIr     { IrVersion=1, Exports: ExportIr[], Types: TypeDeclIr[] (deduped by ClrMetadataName+typeArgs, ordinal order) }
ExportIr    { Name, ClrNamespace, Targets(flags), Location, ServerApi: InterfaceIr, ClientApi: InterfaceIr,
              Handshake{Version?, ServerNexusHash, ClientNexusHash}, ClientAcceptedIds: (hash,id)[], Docs }
InterfaceIr { ClrName, Hash, Methods[], Collections[], Versions{Version, Hash, MethodIds[]}[] }
MethodIr    { Name, Id, Hash, Return(Void|Task|TaskOf TypeRef), Params ParamIr[], SerializedCount, HasCancellation,
              Pipe(None|DuplexPipe|Channel TypeRef), SeparatePool, IsAuthorized, Docs, Location }
ParamIr     { Name, Kind(Value|CancellationToken|DuplexPipe|DuplexChannel), Type?, WireIndex, Nullable }
CollectionIr{ Name, Id, Hash, Kind(List), Mode, Item TypeRef, IsAuthorized }
TypeRef     = Prim(kind) | Bin(clrKind) | PrimArray(elemKind, clrKind) | Seq(elem, clrKind) | Set | Queue | Stack
            | Map(k,v,clrKind) | Tuple(elems, Value|Ref|KVP) | Nullable(inner) | Decl(id, typeArgs) | TypeParam(ordinal)
            | External(clrName)      (+ RefNullable flag on reference occurrences)
TypeDeclIr  = ObjectDecl{Id, ClrMetadataName, Name, ContainingTypes, IsStruct, IsRecord, TypeParams, BaseDeclId?,
                         ArrayLength, IsRecursive, Members{Name, Key, Type, RefNullable, WasNonPublic, DefaultLiteral?, Docs}[]}
            | UnionDecl{Cases{Tag, CaseDeclId, InheritanceDepth}[], IsInterface}
            | EnumDecl{Underlying, IsFlags, Members{Name, Value}[]}
```

## Steps
1. **Records.** Implement the records with value equality. Use the generator's `EquatableArray`.
2. **Projection.**
   - `ShapeToIr` converts `TypeShape` → `TypeRef`/`TypeDeclIr`.
   - `InterfaceToIr` converts `InvocationInterfaceData` → `InterfaceIr`.
   - `HandshakeIr` precomputes:
     - the version string: the last version or null, exactly as `NexusSession.StartAsClient` derives it;
     - both nexus hashes;
     - the accepted incoming `(hash,id)` set.
3. **Merge.** Merge IR fragments deterministically across producers (nexus classes, assembly attributes, `[NexusObject]` types), in ordinal order.
4. **JSON.** `IrJson.Write(NexusIr) → string`: deterministic, sorted keys, no timestamps. Also write `IrJson.Read` for tests and future out-of-tree consumers.
5. **Docs.** `docs/internals/nexnet-ir.md`: every field, the versioning policy (bump `IrVersion` on any breaking change), and an example.
6. **Tests:**
   - snapshot JSON for the test nexuses, plus a fixture covering unions, generics, enums and ext 78;
   - determinism: build twice and compare equal;
   - hash fields equal the values in the existing `NexusGenerationData`.

## Acceptance
- All existing generator tests pass with no changes to the C# output.
- The IR JSON snapshots are reviewed.
