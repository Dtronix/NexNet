## Steps
1. **Node host** (H05 contract).
   - Startup: dial the control port, send hello with the capabilities (Node: all except QUIC; UDS on, FakeTime on), and run the dispatcher with the test-scoped handle table.
   - Implements the generic ops and the named handlers.
   - The ping reply never blocks; respond from the socket callback.
   - `host.dumpThreads` returns `process.report.getReport()`.
   - About 1.5–2k lines.
2. **`host.json`.** `npm run build:host` writes `artifacts/interop/node/host.json` with `{command:"node", args:[".../interop-host-node/src/main.js"], cwd}`.
3. **Browser host.**
   - A Node launcher starts a WS↔TCP bridge and opens a Playwright Chromium page. Firefox and WebKit are selectable with `--browser`.
   - The page loads the browser host bundle: the same dispatcher, with capabilities restricted to WSS, no `Authorization`, no client cert or pinning.
   - It writes `artifacts/interop/browser-<engine>/host.json`.
4. **Self-test.** With the interop server from H07 running, `npm run selftest:host` performs connect, invoke and pipe echo.
5. **Enable the JS rows.** `NEXNET_TEST_LANGS=node` (and `browser`) runs the ported P01 tests with no host-side changes.

## Acceptance
The three H04 sample tests pass on the `node` and `browser-chromium` rows.
