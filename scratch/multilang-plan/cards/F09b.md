## Must cover
1. **Connect.** The client invokes the collection ID with `[pipeByte]` and `IgnoreReturn|DuplexPipe`. The server streams a channel of union messages.
2. **Modes.** ServerToClient and BiDirectional, and what a client write does in each.
3. **Union messages.** For every message:
   - its tag and fields;
   - what `version` means;
   - flags bit 0 (Ack), which is echoed only to the originator;
   - Noop+Ack for transforms that become no-ops.
4. **Reset sequence.** Start → Values* → Complete. Operations received during a reset are buffered, then Ready is signalled.
5. **Stale-op rule.** An op with `version <= current` is discarded.
6. **Versioning and conflicts.** The client sends its op's base version. The server transforms ops; there is no client-side OT.
7. **Shutdown.** Disable and disconnect, Unauthorized handling, and re-enable after reconnect. Collections are not resumed automatically.
8. **Equality for `Remove(item)`.** C# uses `EqualityComparer<T>.Default`, so other languages need value equality.
9. **Sequence diagrams** for: an add, conflicting concurrent ops, and a reset.
