## Emitted when `EmitMode.TestScaffolding` (NexNetTarget option `EmitTestScaffolding=true`; only the interop test project sets it)
1. **Scriptable client nexus.** `<Client>ScriptableNexus extends <Client>NexusBase`. Each method looks up the current script for `(test, method)` and runs its steps in-host:
   - return, throw(kind), delay, awaitSignal, awaitCancel, invoke;
   - named(handler);
   - forward, which sends `evt callback.enter` and awaits `callback.reply`.

   It reports `callback.enter`/`exit` events with the typed-JSON arguments.
2. **Dispatch tables.** `invokeByName(proxy, method, typedJsonArgs, {signal}) → typedJsonResult`, using the generated formatters and converting to and from the typed-JSON value model (H03/H05).
3. **Test codec.** Typed JSON ↔ JS values for the interop zoo types.
4. **`schemaHash`** constant, equal to the H05 definition.
