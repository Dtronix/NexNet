# H06 — Generator CSharpTest target: remote proxies + script facades

| Size | Lands on | Requires | Unblocks | Branch |

## Goal
Generate C# test-side code so ported tests keep their typed nexus API while running against remote clients.

## Owns
- `src/NexNet.Generator/Targets/CSharpTest/**` (new)
- `src/NexNet.Generator/NexusGenerator.cs` (**hot**)
- `src/NexNet.Generator/DiagnosticDescriptors.cs` (**hot**): NEXNET049 if needed
- an opt-in assembly attribute `[assembly: NexusTestScaffolding]` in `src/NexNet/Internals` or a new test-only namespace
- generator tests

## Emitted (only in assemblies with `[assembly: NexusTestScaffolding]`, i.e. `NexNet.Interop`/`IntegrationTests`)
1. **Remote proxy.** `Remote_<IServerNexus> : <IServerNexus>`. Every method forwards via an `IRemoteInvoker` (defined in H04's assembly; reference it by name only).
   - `CancellationToken` parameters are mapped to remote tokens; `RemoteCancel.After(ms)` is supported.
   - Pipe and channel parameters get `IRemotePipe` overloads.
   - Collections are exposed as `IRemoteList<T>`.
2. **Script facade.** `<ClientNexus>Script`: one `ScriptSlot<TArgs, TResult>` per client-nexus method, with:
   - `.Returns(v)`, `.Throws(kind, msg)`, `.Delay(ms)`, `.AwaitSignal(name)`, `.AwaitCancel()`;
   - `.Invoke(m, args)` and `.Named(handler)`, `.Forward(lambda)`;
   - `.Times(n)` and `NextCallAsync()`.

   Plus `OnConnected` and `OnDisconnected` slots.
3. **Argument codecs.** Typed-JSON argument and result codecs per method, using the H03 value model.

## Note
H04 and H06 are developed against the same `IRemoteInvoker`/`ScriptSlot` names. **H06 defines these interfaces** in `src/NexNet.Interop.Abstractions/` (new, tiny project). H04 implements them. That is why H06 precedes H04.
