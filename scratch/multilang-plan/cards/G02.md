# G02 — Opt-in surface: NexusTargets, NexusClientExport, NexusTargetFormatter

| Size | Lands on | Requires | Unblocks | Branch | Decisions |
|---|---|---|---|---|---|
| M | train | G01 | G03 | `mt/G02-opt-in-surface` | D9, D12 |

## Owns
- New public types in `src/NexNet/`:
  - `NexusTargets.cs`: `[Flags] enum NexusTargets { None=0, Java=1, JavaScript=2 }`. Reserve the comment slots `Rust=4, Cpp=8`.
  - `NexusAttribute.cs`: add the `Targets` property.
  - `NexusClientExportAttribute.cs`: `[assembly: NexusClientExport<TServer,TClient>(Targets=…, Name=…)]`, AllowMultiple.
  - `Serialization/NexusTargetFormatterAttribute.cs`: `[assembly: NexusTargetFormatter<T>(NexusTargets target, string nativeFormatterFqcn)]`, AllowMultiple.
- `src/NexNet.Generator/Extraction/**`: parse the above.
- `src/NexNet.Generator/NexusGenerator.cs` (**hot**): wire the IR build into the pipeline when any export has targets. **No emission yet.** Produce an `IncrementalValueProvider<NexusIr?>` consumed by later cards.
- `src/NexNet.Generator/DiagnosticDescriptors.cs` (**hot**): NEXNET043 and NEXNET048 only.
- `llm-usage.md` (**hot**): the new attributes section.
- `docs/articles/` (new `multi-language-clients.md` stub: opt-in only).

## Steps
1. **Attributes and docs.** Add the attributes with XML docs.
2. **Extraction:**
   - `Targets` on a `[Nexus]` server class creates an export, named after the class.
   - `NexusClientExport` takes two interface symbols and **no class**; reuse `ExtractInterfaceData`.
   - `NexusTargetFormatter` entries go into the IR as `External(clrName)` with a per-target native FQCN map. Extend `TypeRef.External`; this is an IR **additive** change, allowed before G01 is consumed elsewhere. Otherwise raise a C-amendment.
3. **Diagnostics:**
   - NEXNET043 (Error): `Targets` set on a Client nexus.
   - NEXNET048 (Error): invalid `NexusTargetFormatter` — empty FQCN, `None` target, or a duplicate for the same (T, target).
4. **Tests:**
   - an export from an attribute;
   - an export from an assembly attribute, covering the V1 interface case;
   - a target-formatter mapping lands in the IR;
   - both diagnostics fire.

## Acceptance
- With no targets set anywhere, behavior is identical to before.
- The IR is reachable in the pipeline.

## Verify
The full C# gate.
