# H01 — C# test refactor: remove client-only hooks, barriers, scaled timeouts

| Size | Lands on | Requires | Unblocks | Branch |
|---|---|---|---|---|
| L | train | T05 | P01* | `mt/H01-test-refactor` |

## Goal
Make the bucket-A (client-facing) tests portable **before** porting them. This card changes how the tests observe behavior, without changing what they test. It is valuable on its own: the C# suite gets less flaky.

## Owns
- the bucket-A test files listed in report §5.1 / Report 3 §1 (e.g. `NexusClientTests*.cs`, `NexusServerTests_{ReceiveInvocation,SendInvocation,Cancellation,Authorization,Versioned}.cs`, `Pipes/**` client/server tests, `Collections/**` client tests, `InvocationCreditTests.cs`, `LargeValueTests.cs`, `RemoteExceptionDetailTests.cs`, `TlsCertificateTests.cs`, `ReconnectionPolicyTests.cs`)
- `src/NexNet.IntegrationTests/BaseTests.cs` (**hot**)
- `TaskExtensions.cs`, `Utilities.cs`
- `src/NexNet/Transports/ConfigBase.cs` (**hot**): add an internal `InternalOnReceive` tap, if not present

## Steps
1. **Replace client-side taps with server-side observation.**
   - `clientConfig.InternalOnSend` (13 uses) becomes a server-side `InternalOnReceive`.
   - `InternalOnClientConnect` becomes `OnConnected`.
2. **Replace sleeps used to order steps** (157 `Task.Delay` calls) with signals: a server-side `TaskCompletionSource` or a callback-entered event. Keep a delay only where the test is about time itself.
3. **Scaled timeouts.** Add `T(double seconds)`: seconds × `NEXNET_TIMEOUT_SCALE` (default 1), plus 250 ms of slack. Convert `.Timeout(x)` in bucket-A files to `.Timeout(T(x))`.
4. **Negative assertions.** Wherever a test asserts that "nothing arrives", add a barrier: a round-trip invocation that guarantees ordering.
5. **Async state reads.** Code that reads `client.State` synchronously right after an action becomes `WaitForState(...)`.
6. **Pipe and channel helpers.** Pipe/channel tests must not use `GetChannel<T>()` extensions on internal `ReaderCore`/`WriterCore` from test bodies. Route them through helper methods that P01 can later map to `IRemotePipe`.

## Acceptance
- Same test count.
- Green in parallel, 5 runs in a row.
- `grep InternalOnSend` finds no bucket-A test.

## Verify

- `NEXNET_TIMEOUT_SCALE=3` run once.
