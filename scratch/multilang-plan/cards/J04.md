## Emitted per export (`<module>/<ExportName>.js` + `.d.ts`)
1. **Handshake descriptor constant.** `version`, both hashes and `acceptedIds`, taken from the IR. The hashes are never recomputed.
2. **`<Server>Proxy extends ProxyBase`.** One method per server method:
   - `void` methods become `m(args): void`;
   - `ValueTask` becomes `Promise<void>`, and `ValueTask<T>` becomes `Promise<T>`;
   - an options parameter `{ signal }` comes last when the C# method has a `CancellationToken`;
   - pipe methods take a `NexusDuplexPipe`;
   - channel methods take `NexusChannelWriter<T>`/`Reader<T>` built with the generated formatter.

   Collections are exposed as `NexusList<T>` getters.
3. **`<Client>NexusBase extends ClientNexusBase`.**
   - Abstract methods per client-nexus method, async allowed.
   - A generated `_dispatch(methodId, reader, ctx)` switch that decodes the arguments, calls the method and encodes the result.
   - Honors `SeparatePool` flags (the runtime pool selection) and the cancellation token → `AbortSignal` mapping.
4. **Factory.** `create<Export>Client(config, nexus)` wires the handshake descriptor, the proxy class and the dispatcher.
5. **Docs.** JSDoc copied from the C# XML docs.
