## Owns

- tests

## Steps
1. **Reconnection.** A `ReconnectionPolicy` interface with a default `shouldReconnect`. The default policy delays 0, 2, 10 and 30 s.
2. **Client pool.** `NexusClientPool`, built on a `Semaphore` with a scheduled health check.
3. **Logging.**
   - A `NexusLogger` interface, with console and rolling implementations.
   - **No SLF4J or `android.util.Log` in core.** Those adapters belong to K13 or are documented.
4. **Metrics.** A `NexusMetricsListener` SPI with identical instrument names and tags.
5. **Snapshots.** Immutable snapshot classes. A test checks the field names against `tests/golden/snapshot-fields.json` (produced in J10; if J10 hasn't merged, produce the file here, and whichever lands second rebases).
6. **Leak audit.** `Diagnostics.counters()`.
