# P04 — Merge the train into master + release notes

| Size | Lands on | Requires | Branch |
|---|---|---|---|
| S | train → master | P02, P03 | `train/multilang` (merged as a PR) |

## Steps
1. **Release notes.** Write `docs/articles/releases/<version>.md`. It must cover:
   - **Behavior changes:** pre-send cancellation now throws (F03); `Map*` with a non-primary config applies that config's settings (S02); new `NexusServerState` values (S01); and the `ServerGreeting` `idleTimeoutMs` field (S04: pre-1.0, so upgrade servers and clients together).
   - **New features:** Java and JS clients; the multi-endpoint server; `Context.Endpoint`; WebSocket `AllowedOrigins`; the query-string token; async `Authenticate`; `IsSecure`; the plaintext warning; NEXNET040–049.
   - **Test infrastructure:** the TUnit migration and the new test commands.
2. **Merge master into the train**, resolve any conflicts, and run the full gate including the nightly matrix once.
3. **Open the train → master PR**, with a summary table of every merged unit and its PR link.
4. **After the merge,** follow `llm-release.md` (P03) for a lockstep release, then delete the `mt/*` branches.
