## Steps (follow F09b's state machine exactly)
1. **`NexusList<T>`.**
   - `enable()`, `disable()`, `ready` and `disabled` promises, `state`.
   - Local reads: `[Symbol.iterator]`, `at(i)`, `length`, `toArray()`.
   - Mutations return `Promise<boolean>` resolved by the Ack: `add`, `insert`, `remove(item)`, `removeAt`, `replace`, `move`, `clear`.
   - Events via `EventTarget` `changed`: `{action: add|remove|replace|move|reset|ready, …}`.
   - Mutations throw in read-only (ServerToClient) mode.
2. **Connect** by invoking the collection ID with `[pipeByte]` (`IgnoreReturn|DuplexPipe`), then read the union channel.
3. **Versioned apply.** Ops are applied sequentially:
   - the reset sequence buffers ops;
   - stale ops (`version <= current`) are dropped;
   - Ack and Noop are handled;
   - each op carries its base version;
   - one op in flight at a time (the OperationLock equivalent).
4. **Equality.** `remove(item)` uses the generated `equals` from J03, falling back to `===` for primitives.
5. **No resume.** After a reconnect the list is disabled; the app re-enables it, as in C#.
