## Steps
1. **New wire field.** Add a trailing field `idleTimeoutMs` (uint32) to `ServerGreeting`, set to the endpoint's `Timeout` (per-endpoint via S02).
   - Readers must tolerate its absence. This is the trailing-field rule; follow the existing message-array extension rules.
2. **Client ping interval:**
   - When `ClientConfig.PingInterval` is not explicitly set, the client uses `idleTimeoutMs / 3`, with a minimum of 1 s.
   - An explicit `PingInterval` greater than or equal to the advertised timeout logs a warning.
   - Snapshots expose the effective interval.
3. **Spec update.** Update the ServerGreeting body section and resolve the G1 note.
4. **Tests:**
   - a 6 s server timeout gives the client a ping interval of about 2 s;
   - an explicit interval is respected;
   - the golden greeting vector is updated.

## Acceptance
Mobile and browser clients can rely on the server to tell them how often to ping.

The full C# gate.
