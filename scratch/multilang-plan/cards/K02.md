## Steps
1. **Writer and reader.**
   - Pooled `byte[]` buffers.
   - Big-endian MessagePack.
   - Canonical smallest encoding.
   - Ext 78 arrays via `ByteBuffer.order(LITTLE_ENDIAN).as*Buffer()`.
   - The same hardening options as C#: MaxDepth, MaxElements, strict UTF-8 via `CharsetDecoder` with `REPORT`.
2. **Formatters for every built-in type**, per `01-context.md` §5:
   - C# `byte` → `int` (range-checked);
   - `ushort` → `int`;
   - `uint` → `long`;
   - `ulong` → `long` holding the raw bits, with unsigned helpers;
   - `Half` → `float` (manual float16 conversion);
   - `Guid` → `UUID`;
   - `BigInteger` with reversed byte order;
   - ext 78: `char[]` for `ushort`, `int[]` with raw bits for `uint`, `short[]` with bits for `Half`.
3. **Value types.** Exact round-trip, including the `DateTime` Local encoding and `decimal` flags. Add `java.time` and `BigDecimal` converters as methods, with no `java.time` in signatures (API 24).
4. **Golden tests.** A JUnit 5 `@TestFactory` over `tests/golden/*.jsonl`, located via a system property set by Gradle (`-Dnexnet.golden=${rootDir}/../../tests/golden`), covering all modes.
5. **API-24 check.** Animal Sniffer must pass.
