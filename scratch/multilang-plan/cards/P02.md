## Content
1. **Opt-in and MSBuild configuration**, with a worked example: one `.csproj` emitting Java and JS.
2. **Feature parity table**, generated from the capability flags and the test-matrix results where feasible. It must list every **documented exception** and its workaround:
   - browser TLS and header limits;
   - Java has no UDS;
   - QUIC is .NET-only;
   - `AsyncLocal` flow is platform-specific.
3. **Getting started for each language:**
   - install `@dtronix/nexnet` / `com.dtronix:nexnet-client`;
   - generate code;
   - connect over HttpSocketTls and WSS;
   - auth via the greeting token;
   - pipes, channels and collections examples;
   - cancellation (`AbortSignal` / `CancellationToken`);
   - Android notes: the lifecycle AAR, `callbackExecutor`, no main-thread IO;
   - browser notes: WSS only, `AllowedOrigins`, background tabs.
4. **Type mapping table** (normative).
5. **Multi-transport server docs** (cross-link S02).
