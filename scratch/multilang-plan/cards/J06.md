# J06 — JS transports

| Size | Lands on | Requires | Branch | Decisions |
|---|---|---|---|---|
| M | train | J05, F09c | `mt/J06-js-transports` | D5, D6 |

Transports: WSS (browser), RFC 6455 (Node), HttpSocket, TCP/TLS, UDS.

## Owns
- `clients/js/packages/nexnet/src/transport/**`, except `ITransport.js`
- `clients/js/packages/nexnet/src/node.js` exports
- `test/transport/**`

## Steps
1. **Browser WebSocket.**
   - Native `WebSocket(url)` with `binaryType='arraybuffer'` and **no subprotocol**.
   - Concatenate incoming messages into the session buffer.
   - Send backpressure by polling `bufferedAmount` against a high-water mark.
   - `isSecure` follows the `wss:` scheme; `remoteCertificate` is null.
2. **Node RFC 6455 client** (`src/transport/node/ws.js`). Built over `https.request`/`http.request` with `Upgrade: websocket`. Must implement:
   - the Sec-WebSocket-Key/Accept check;
   - client masking;
   - fragmentation reassembly;
   - ping/pong;
   - the close handshake;
   - forwarding of the `head` bytes.

   TLS options: `ca`, `cert`/`key`/`pfx`, `servername`, `checkServerIdentity` (SPKI pinning) and `rejectUnauthorized`. Optional `Authorization` header and query token.
3. **Node HttpSocket.** `https.request` with `Connection: Upgrade` and `Upgrade: nexnet-httpsockets`, `ALPNProtocols:['http/1.1']`, and the `upgrade` event. **Feed `head` to the session first.** A non-101 status maps to the error kinds per F09c.
4. **Node TCP and TcpTls.** `net.connect` / `tls.connect` with the same TLS options.
5. **Node UDS.** `net.connect({ path })`.
6. **Remote certificate.** Expose `remoteCertificate` (`getPeerX509Certificate`) on the Node TLS transports.
7. **Tests.** Against a minimal local Node test server for framing edge cases: fragmented WS frames, the 101 response and the preamble in the same packet, close codes. Real C# interop happens in J12/P01.
