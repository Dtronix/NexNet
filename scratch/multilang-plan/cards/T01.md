## Goal
Move every test project to Microsoft.Testing.Platform (MTP) while still on NUnit. TUnit is MTP-only, and once the root `global.json` selects MTP, every test project must use it. This step enables a side-by-side migration and moves docs and CI to the MTP syntax early.

## Owns
- `global.json` (new, repo root): `{"test":{"runner":"Microsoft.Testing.Platform"}}`. No `sdk` section.
- The three test `.csproj` files:
  - add `<EnableNUnitRunner>true</EnableNUnitRunner>` and `<OutputType>Exe</OutputType>`;
  - remove `Microsoft.NET.Test.Sdk` and `NUnit3TestAdapter` if NUnit's MTP runner makes them redundant (verify);
  - remove the unused `Microsoft.AspNetCore.Mvc.Testing` from IntegrationTests (confirm it has no usages first).
- `src/NexNet.slnx` (**hot**): add `global.json` under Solution Items.
- `.github/workflows/dotnet.yml` (**hot**):
  - `dotnet test <proj> -c Release --no-build -- --report-trx --results-directory TestResults`;
  - upload TRX on failure;
  - `--minimum-expected-tests <n>` per suite, set to the current case counts.
- `llm-dev.md` (**hot**, lines ~28–34) and `llm-release.md` (**hot**, ~116–124): replace `--filter "FullyQualifiedName~X"` with `--treenode-filter "/*/*/*/X"`, and document the class form `/*/*/X/*`.

## Steps

2. Make the changes above.
