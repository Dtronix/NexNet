## Steps
1. **Move the test interfaces.** The integration tests must still compile and pass.
2. **Interop type zoo.** Echo methods for every built-in type in spec §10.4, plus:
   - `[NexusObject]` classes, structs and records;
   - unions (abstract class and interface);
   - generics;
   - enums, including `[Flags]` and long-backed;
   - nullable variants;
   - dictionaries with string, int and Guid keys;
   - sets, stacks and queues;
   - ext 78 arrays of every primitive;
   - large values above 64 KiB;
   - pipe- and channel-typed methods;
   - an `INexusList<InteropItem>` collection;
   - a `[NexusVersion]` pair;
   - `[NexusAuthorize]` methods;
   - a `SeparatePool` method;
   - a type with a user `[NexusFormatter]` plus a `NexusTargetFormatter` mapping (D12).

   Set `Targets = Java | JavaScript` on the interop server nexus, so the generator emits for it once G04+ exists. With no output dirs configured, NEXNET044 is a warning, so silence it via the MSBuild target properties pointing at `artifacts/interop/<lang>/generated`. That is fine because this is a test project.
3. **Frame injection.** Lets tests send arbitrary frames to a client, e.g. a malformed remote-error detail. Used by `RemoteExceptionDetailTests` once ported.
4. **Smoke test.** A few C# tests call the zoo echo methods over UDS.
