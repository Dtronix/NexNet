## Format
- One JSON object per line:

  ```json
  {"id":"u64.max","type":"ulong","value":"18446744073709551615","hex":"cf…","mode":"both"}
  ```
- `mode` is one of:
  - `both`: encode the value and compare to `hex`, and decode `hex` and compare to `value`;
  - `decode`: decode only; covers non-canonical but accepted input;
  - `reject`: decoding must fail, with an optional `error` kind.
- `options` sets serializer options: Untrusted/Trusted, MaxDepth, StrictUtf8.
- Typed JSON for values:
  - integers beyond 2^53 are strings;
  - floats are bit-pattern strings `"f64:0x…"`, so NaN and -0 survive;
  - bytes are base64;
  - objects are arrays by key;
  - unions are `[tag, value]`;
  - enums are their underlying number;
  - DateTime and similar types are raw tick fields.
- `type` is a zoo type name or a built-in alias.

## Steps
1. **Seed the tool's vectors** from:
   - `WriterGoldenTests` boundaries;
   - `ProtocolMessageTests` goldens;
   - `PrimitiveArrayTests`;
   - `GeneratedFormatterTests`;
   - the fuzz corpus.

   Required edge cases:
   - u64 above `Long.MAX_VALUE` and above 2^53;
   - `char` and `Half`;
   - `DateTime` of every kind, including Local;
   - `decimal` flags;
   - `Guid` byte order;
   - invalid UTF-8;
   - float32 vs float64.

   Cross-check against MessagePack-CSharp where it applies.
2. **Generate mode.** `dotnet run --project src/NexNet.GoldenVectors -- --out tests/golden` must be deterministic.
3. **C# replay.** `GoldenReplayTests` replays every line in C#.
4. **Freshness test.** A test regenerates the vectors into a temp dir and fails if they differ from the checked-in files. CI catches stale goldens this way.
