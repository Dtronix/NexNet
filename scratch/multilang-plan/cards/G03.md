## Diagnostics

| ID | Severity | Fires when |
|---|---|---|
| 040 | Error | A type is unsupported in the target, e.g. a user formatter without a `NexusTargetFormatter` for that target |
| 041 | Error | Names collide after mapping |
| 042 | Error | Overloads across exported interfaces (reuse F02's descriptor) |
| 044 | Warning | A target is opted in but has no output dir (`NexNetTargets` property lacks it) |
| 045 | Error | Unknown target, or Java `Package` missing |
| 046 | Warning | A set or dictionary key type compares by reference in JS |
| 047 | Error | Output file collision |
