# T05 — IntegrationTests parallel-safety

| Size | Lands on | Requires | Unblocks | Branch |

## Owns
- `src/NexNet.IntegrationTests/**`, including `BaseTests.cs` (**hot**)
- `src/NexNet/NexusServer.cs` (**hot**; only to stop exposing `ResetIdCounter`, if it becomes unused)

## Steps
1. **Ports.** Replace `FreeTcpPort()`/`FreeUdpPort()`, which have a bind-close-reuse race:
   - Bind servers on port 0 and read back the actual port. Add a `ServerConfig` accessor if one is needed.
   - Otherwise use a process-wide unique port allocator.
2. **UDS paths.** Give each test its own directory.
3. **Session ID counter.** Tests must not depend on the static `ResetIdCounter()` (`BaseTests.cs:99`). Assert relative to the first observed ID, or use per-server ID providers.
4. **Teardown.** Teardown must be awaited and bounded.
5. **Enable parallelism.** Remove `[assembly: NotInParallel]` and enable parallel execution class by class. Keep `[NotInParallel("stress")]` on metrics, session-budget, rate-limit and `SnapshotListTests` stress tests that use `Thread.Sleep`/`Parallel.Invoke`.
6. **Timeouts.** Introduce `T(x)` scaled timeouts here only if parallel load makes `.Timeout(1)` flaky. H01 does the full timeout pass.

## Acceptance
- The suite passes **5 consecutive runs** in parallel with no failures.
- Wall-clock time is at or below the serial baseline.
