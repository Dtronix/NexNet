## Steps
1. **Package and file layout.** The package comes from the `NexNetJavaPackage` option. One file per type, under `<package>/types/`.
2. **`[NexusObject]` classes.**
   - POJOs with a no-arg constructor, an all-args constructor, and getters/setters, or public final fields for record-like structs (decide and document).
   - **Generated `equals`/`hashCode`/`toString`** for structs and records. Equals is always generated for types used in `Remove(item)` or as set/map keys.
   - JSpecify `@Nullable`.
3. **Enums: open value classes.**
   - `final class Color { public static final Color RED = new Color(0); …; int value(); static Color of(int) }`.
   - They round-trip unknown and `[Flags]` values, with `or`/`has` helpers for flags.
4. **Unions.** An abstract base class or an interface, plus case classes.
5. **Generics.** `Box<T>` with `BoxFormatter.of(Formatter<T>)`.
6. **Nested types.** Static nested classes, or `Outer_Inner` names when there is a collision.
7. **Formatters.** `<package>/formatters/Formatters.java` exposes a `public static final Formatter<X>` constant per type. The logic ports `EmitObject` and `EmitUnion`, as in J03 §2.
8. **Target formatters (D12).** Reference the user's FQCN class, which must implement `Formatter<T>`. Also emit `<package>/formatters/UserFormatters.java` documenting the required classes. Leaving one missing fails `javac`.
9. **Tests.**
   - Text snapshots.
   - SDK-gated: `javac --release 11` over the output against the K01 jar (built via `gradlew :nexnet-client:jar`, located by path).
   - SDK-gated: a round-trip runner comparing the bytes with C#.
