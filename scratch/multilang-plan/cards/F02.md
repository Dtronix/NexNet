# F02 — Generator: duplicate/overloaded method names → NEXNET042; real diagnostic locations

| Size | Lands on | Requires | Branch |
|---|---|---|---|
| S | **master** | — | `mt/F02-dup-method-names` |

## Problem (verified)
- **Generator crash.** `src/NexNet.Generator/Extraction/NexusDataExtractor.cs:926` runs `allMethods.ToDictionary(m => m.Name, m => m.Id)`. It throws on overloaded or same-named inherited methods, so the generator crashes instead of reporting a diagnostic. Line 73 has the same pattern for authorization data.
- **Lost locations.** `NexusGenerator.ReportSerializationDiagnostics` reports serialization diagnostics with `Location.None`, even though they carry `LocationData`.

## Owns
- `src/NexNet.Generator/Extraction/NexusDataExtractor.cs`
- `src/NexNet.Generator/Validation/NexusValidator.cs`
- `src/NexNet.Generator/DiagnosticDescriptors.cs` (**hot**; append NEXNET042 only)
- `src/NexNet.Generator/NexusGenerator.cs` (**hot**; the location fix only)
- New tests in `src/NexNet.Generator.Tests/`
- A release-note line in `docs/articles/releases/`

## Steps
1. Add `NEXNET042` (Error) with this message: "Nexus interface '{0}' declares more than one method named '{1}'; method names must be unique across the interface and its inherited interfaces."
   - Detect the duplicates before ID assignment.
   - When they are present, skip both dictionary builds and skip emission for that nexus.
2. Report each serialization diagnostic at its `LocationData`. Fall back to `None` only when it has no location.
3. Add tests:
   - an overload within one interface;
   - the same method name across inherited interfaces;
   - versioned interfaces.

   Each test asserts NEXNET042 is reported and no exception is thrown. Add one more test asserting that a serialization diagnostic now has a real location.

## Acceptance
- The generator never throws on duplicate names.
- For valid nexuses, the generated C# is byte-identical: existing generator snapshot tests pass unchanged.

## Verify
- `dotnet test src/NexNet.Generator.Tests -c Release`
- The full C# gate.
