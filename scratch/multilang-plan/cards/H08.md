# H08 — CI workflows: golden, interop matrix, nightly

| Size | Lands on | Requires | Branch | Decisions |
|---|---|---|---|---|
| M | train | H05, F01 | `mt/H08-ci` | D26, D27, D29 |

The interop jobs only become *required* after J12/K12. Before that, they run with `continue-on-error` or are skipped when the hosts don't exist.

## Owns
`.github/workflows/*` (**hot**): `dotnet.yml` (existing), and the new `clients.yml` and `nightly.yml`

## Jobs
1. **`dotnet`** (existing): the C# gate on ubuntu-26.04, with no JDK or Node installed. This keeps proving D27.
2. **`golden`:**
   - run the freshness check;
   - JS: `npm ci && npm test -- golden` in `clients/js`;
   - Java: `gradlew :nexnet-client:test --tests '*Golden*'` in `clients/java`.
3. **`js`:**
   - Node 22 and 24;
   - `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`;
   - Vitest browser mode with Chromium.
4. **`java`:**
   - setup-java Temurin 21 to build;
   - a matrix test runtime of 11 and 21 via Gradle toolchains;
   - `gradlew check` (includes Animal Sniffer API-24).
5. **`interop`:**
   - matrix over `node`, `java` and `browser-chromium`;
   - build the hosts (`npm run build:host` / `gradlew :interop-host:installDist`);
   - `dotnet test src/NexNet.IntegrationTests -c Release` with `NEXNET_TEST_LANGS=<lang>`, `NEXNET_REQUIRE_SDKS=1` and a tree filter on the `[Lang=<lang>]` property;
   - transports: `HttpSocketTls` and `WebSocketTls`.
6. **`nightly.yml`:**
   - the full transport matrix, including plaintext, TCP, TcpTls and Node UDS;
   - browsers: Chromium, Firefox and WebKit (Playwright);
   - **Android** (D26):
     - `android-actions/setup-android`;
     - build `nexnet-client-android`;
     - run D8/R8 over the core JAR with `--min-api 24`;
     - smoke-test on an API-24 emulator (`reactivecircus/android-emulator-runner`): connect, invoke, open a pipe, all against the interop server reachable from the emulator at 10.0.2.2;
   - a 10× repeat stress run of the interop suite.
7. **Artifacts on failure:**
   - TRX and JUnit XML;
   - control transcripts;
   - host logs;
   - thread dumps and Node reports;
   - Playwright traces.
8. **Caching:** NuGet, Gradle (`gradle/actions/setup-gradle`), npm and Playwright browsers.
