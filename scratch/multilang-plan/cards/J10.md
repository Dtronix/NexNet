## Steps
1. **Reconnection.**
   - A `ReconnectionPolicy` interface: `{ reconnectDelay(n): number|null, shouldReconnect?(reason) }`.
   - Default delays 0, 2, 10 and 30 s, continuous.
   - The default should-reconnect reasons match C#: SocketError, Timeout, ServerRestarting.
   - Reconnect uses greeting 101.
   - Hooks: `onReconnecting` and `onConnected(true)`.
   - **Browser build:** reconnection on by default, reconnect on `visibilitychange`, `online`, and `freeze`/`resume`.
2. **`NexusClientPool`.** `maxConnections`, `maxIdleTime`, `minIdleConnections`, health check, `rent()`, `ensureConnected` and a collection connector, all mirroring `NexusClientPool.cs`.
3. **Logging.** A `NexusLogger` interface (hierarchical paths, behaviors, levels), a console logger and a rolling logger. Never log token bytes.
4. **Metrics.** A listener interface with **identical instrument names and tags** to `docs/articles/metrics.md`. An optional OpenTelemetry adapter is out of scope; document how to bridge.
5. **Snapshots.** `client.getSnapshot()` returns the same field names as `NexusSessionSnapshot`/`NexusClientSnapshot`, camelCased. Add a test that compares the field list against a JSON list exported from C#. Generate that list in this card via a tiny C# test that writes `tests/golden/snapshot-fields.json`.
6. **Leak audit.** `diagnostics.counters()` returns `{sessions, pipes, timers, pendingInvocations, subscriptions}`.
