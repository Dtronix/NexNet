## Owns
- `clients/java/interop-host/**`
- `clients/java/settings.gradle.kts` (**hot**)
- the MSBuild glue in `src/NexNet.TestNexus/*.csproj`: a `NexNetTarget` java item with `OutputDir=$(RepoRoot)artifacts/interop/java/generated`, `Package=com.dtronix.nexnet.interop` and `EmitTestScaffolding=true`

## Steps
1. **Build.** `interop-host` compiles the generated sources from `artifacts/interop/java/generated` (as a Gradle source dir) together with `nexnet-client`, using the `application` plugin.
2. **Host implementation** (H05 contract). It dials the control port and sends hello with these capabilities:
   - all transports except UDS and QUIC;
   - client certificates, pinning and custom CA;
   - fake time;
   - the client pool.

   It runs the dispatcher with the test-scoped handle table, the generic ops and the named handlers. The ping reply runs on a dedicated thread. `host.dumpThreads` uses `Thread.getAllStackTraces()`.
3. **Install.** `gradlew :interop-host:installDist` writes `artifacts/interop/java/host.json`, with the start script path and `JAVA_OPTS` (e.g. `-XX:+UseSerialGC -Xshare:auto` for startup).
4. **Test runtime.** It is selectable via `-Pnexnet.testRuntime=11|21`, so CI can run the host on Java 11.
