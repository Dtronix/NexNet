This card is **atomic**: one project cannot mix NUnit and TUnit. Give it to one agent.

## Owns
- `src/NexNet.IntegrationTests/**`, including `BaseTests.cs` (**hot**)

## Steps
1. **Packages and parallelism.** Swap to the pinned TUnit and add `[assembly: NotInParallel]`.
2. **`BaseTests` lifecycle:**
   - `[SetUp]` → `[Before(Test)]`.
   - `[TearDown]` → `[After(Test)]`, and **await** the disconnect/stop calls (today they are fire-and-forget).
   - The instance `[OneTimeSetUp]`/`[OneTimeTearDown]` at `BaseTests.cs:79,87` → **static** `[Before(Class)]`/`[After(Class)]`, or a `ClassDataSource(Shared = PerClass)` holding `_socketDirectory`.
   - `TlsCertificateTests.cs:24`: move its certificates to a static or class-shared fixture.
   - Remove the `Trace.Listeners` growth.
   - The UDS `_counter` must become global (`Interlocked`) or per-test-directory. TUnit creates one instance per test, so an instance counter collides.
   - Log flush on failure: `ctx.Execution.Result?.State == TestState.Failed`. `BufferedTestLogger` should use `TestContext.Current`.
3. **Transport matrix.** Add a `[Transports]` data-source attribute (`DataSourceGeneratorAttribute<Type>` with an `Except`/`Only` filter). Script-replace the stacked `[TestCase(Type.X)]` rows with it; 394 methods are affected. `LargeValueTests.TransportsAndSizes` becomes a `MethodDataSource`.
4. **Run the code fixer** for the bulk of the conversion. Then fix by hand:
   - the 108 `Assert.Multiple(lambda)` → `using (Assert.Multiple()) { await … }`;
   - about 60 synchronous callback asserts → capture the value, then assert after the await;
   - exact-type throws: `Assert.Throws` 72 and `ThrowsAsync` 55, reviewed per site (`TaskCanceledException` vs `OperationCanceledException`);
   - `byte[]` and collection equality: make sure the TUnit assertion compares elements;
   - `[Repeat(n)]` → `[Repeat(n-1)]` (4 sites);
   - `Assert.Ignore` → `Skip.Test`;
   - `Assert.Pass` → `return`.
5. **Keep source-gen mode.** 84 of the 96 classes are internal.
6. **Docs:** update `llm-dev.md` (**hot**): §4.1 BaseTests, §4.4 the `TestCase` → `[Transports]` recipe and the awaited-assert rule, and the add-test recipe near line 502.

## Acceptance
- The case count is the same as before (2811), or each difference is explained in the PR.
- Green serially.
- The runtime is within about 1.5× of the NUnit baseline (about 4 minutes).
