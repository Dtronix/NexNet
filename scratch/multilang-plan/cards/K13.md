# K13 — Optional Java modules: android, kotlin, okhttp, micrometer

| Size | Lands on | Requires | Branch | Decisions |
|---|---|---|---|---|
| M | train | K12 | `mt/K13-java-optional-modules` | D16, D26 |

**Only the `-android` module needs the Android SDK**, and it is built in the nightly CI job. Locally it builds only when `ANDROID_HOME` is set; otherwise Gradle skips it with a message.

## Owns
- `clients/java/nexnet-client-android/**`
- `clients/java/nexnet-client-kotlin/**`
- `clients/java/nexnet-client-okhttp/**`
- `clients/java/nexnet-client-micrometer/**`
- `clients/java/settings.gradle.kts` (**hot**): conditional include of `-android`
- `clients/java/gradle/libs.versions.toml` (**hot**)

## Modules
1. **`nexnet-client-android`** (an AAR built with AGP; `minSdk 24`; `compileSdk 36`):
   - a main-thread `callbackExecutor`;
   - a `ProcessLifecycleOwner` observer: disconnect on background, which is configurable, and reconnect on foreground;
   - a `ConnectivityManager.NetworkCallback` that reconnects on network change;
   - an `android.util.Log` logger adapter;
   - `consumer-rules.pro` (empty, documented).

   Instrumented smoke test, run nightly on an API-24 emulator: connect to the interop server at `10.0.2.2`, invoke, and pipe-echo.
2. **`nexnet-client-kotlin`:**
   - `suspend` extensions over the generated `CompletableFuture` methods (`kotlinx-coroutines-jdk8` `await`);
   - coroutine cancellation cancels the NexNet token;
   - `Flow<T>` adapters for channel readers and `NexusList` changes.
3. **`nexnet-client-okhttp`.** A WSS transport built on OkHttp `WebSocket`, for apps that already use OkHttp (proxies, interceptors).
4. **`nexnet-client-micrometer`.** A `NexusMetricsListener` that maps to Micrometer meters with the same names.

## Verify
