## Goal
Document and script the toolchains for Java and JS development, without making them required for C# work (D26, D27).

## Steps
1. Write `contributing-multilang.md` with these sections:
   - **C#-only contributors** come first. They need nothing beyond the .NET SDK (D27).
   - **Java:**
     - Any OpenJDK 21. Temurin is recommended: `winget install EclipseAdoptium.Temurin.21.JDK`, sdkman, or apt.
     - Gradle comes from the committed wrapper only.
     - **No Android SDK is needed.** The Animal Sniffer API-24 signature is downloaded from Maven.
   - **Android module only:**
     - Install the Android command-line tools and set `ANDROID_HOME`.
     - Run `sdkmanager "platforms;android-24" "platforms;android-36" "build-tools;36.0.0" "platform-tools" "emulator" "system-images;android-24;default;x86_64"`.
     - This is only needed for `nexnet-client-android` work and the nightly job.
   - **JS:**
     - Node 22 or later; 24 LTS is recommended.
     - Install Playwright browsers with `npx playwright install chromium`. For nightly parity, install all three: `chromium firefox webkit`.
   - **Environment flags:** `NEXNET_TEST_LANGS` and `NEXNET_REQUIRE_SDKS`. See `01-context.md` §2.
   - **Publishing prerequisites** (used by P03):
     - a Sonatype Central Portal account;
     - the `com.dtronix` namespace, verified by a DNS TXT record on dtronix.com;
     - a GPG signing key;
     - the npm org `@dtronix`.
2. Write `check-toolchain.*`:
   - Print found or missing, plus the version, for `dotnet`, `java`/`javac` (major version 21 or later), `node` (22 or later), `npm`, `ANDROID_HOME` and `npx playwright --version`.
   - Exit 0 unless `--require java,node,...` is given and a required tool is missing.

## Acceptance
- A machine with only the .NET SDK passes the C# gate unchanged.
- `check-toolchain.ps1 --require java,node` exits non-zero with a clear message when Java or Node is missing.
