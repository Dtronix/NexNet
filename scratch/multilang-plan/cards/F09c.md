## Must cover
1. **TCP and TLS:** the raw stream, and TLS SNI/ALPN expectations. TLS sends no ALPN; QUIC uses ALPN `nn1`.
2. **HttpSocket:**
   - The exact HTTP/1.1 request:
     - `GET <path>`;
     - `Host`, including the port when it is non-default;
     - `Connection: Upgrade` and `Upgrade: nexnet-httpsockets`;
     - optional `Authorization` and `Origin`;
     - the query token (F06).
   - Success: the `101` response headers.
   - Failure statuses: 401/403 map to AuthenticationError; 500 maps to InternalError.
   - **Bytes after the `\r\n\r\n` belong to the NexNet session.**
   - HTTP/2 extended CONNECT: the server supports it; clients need not use it.
3. **WebSocket:**
   - binary messages only;
   - message boundaries are insignificant, because NexNet frames can span messages;
   - no subprotocol is requested;
   - the close codes used;
   - `AllowedOrigins` and the query token (F06).
4. **UDS:** filesystem paths only; no abstract namespace.
