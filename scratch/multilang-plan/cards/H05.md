## Protocol (write the contract doc first)
- **Carrier:**
  - The C# runner listens on `127.0.0.1:0`.
  - The host is started with the arguments `--control 127.0.0.1:<port> --token <random>` and dials in.
  - The browser host reaches the runner through a WS↔TCP bridge started by the Node launcher.
- **Framing:** `u32 BE length + u8 kind`, where `0x01` is UTF-8 JSON and `0x02` is reserved for binary. Maximum frame size is 64 MiB.
- **Message shapes:**
  - `hello{proto:1, token, lang, runtime, lib, schemaHash, capabilities[], maxConcurrency}`
  - `req{id, test, op, args, timeoutMs}`
  - `res{id, ok, value | error{kind, message, detail}, hostNs}`
  - `evt{test, h, ev, data, hostNs}`
- **Handles** are test-scoped strings. `test.end` returns a leak report covering open clients, pipes, timers, pending invocations and subscriptions.
- **Ops (about 45):**

  | Group | Ops |
  |---|---|
  | Host | `ping`, `test.begin`, `test.end`, `host.dumpThreads`, `host.shutdown`, `log.level` |
  | Client | `client.create{spec}`, `client.connect`, `client.tryConnect`, `client.disconnect`, `client.dispose`, `client.state`, `client.awaitState`, `client.awaitReady`, `client.awaitDisconnected` |
  | Invoke | `invoke{h, method, args, cancel:{token \| afterMs}, detach}`, `future.await`, `future.poll`, `token.create`, `token.cancel` |
  | Scripts | `script.set`, `script.clear`, `signal`, `callback.reply` |
  | Pipes | `pipe.create`, `pipe.ready`, `pipe.write{b64 \| pattern}`, `pipe.read`, `pipe.drain`, `pipe.complete` |
  | Channels | `channel.writer`, `channel.write`, `channel.reader`, `channel.read`, `channel.readAll`, `channel.complete` |
  | Lists | `list.op`, `list.snapshot`, `list.enable`, `list.disable` |
  | Other | `time.advance`, `pool.*` |
  | Named handlers | `pipe.echo`, `pipe.drain`, `pipe.readExact`, `channel.pump{count, size, delayMs}`, `channel.echo` |
- **Values:** typed JSON, as in H03.
- **`schemaHash`:** the sha256 of the IR JSON of the TestNexus exports. A mismatch fails the run with the exact rebuild command.

## C# side
1. **`RemoteClientDriver : IClientUnderTest`.** Wraps the protocol; error kinds are rethrown as C# exceptions.
2. **`LanguageHostPool`.** A TUnit `ClassDataSource` shared per test session, keyed by language, with `IAsyncInitializer`.
   - Launches the host and runs a warm-up self-test.
   - Pings every 1 s. If no pong arrives for 5 s, or the process exits, it:
     - captures a thread dump (`jcmd <pid> Thread.print` / `host.dumpThreads`, or `process.report` for Node) and the stderr tail;
     - fails in-flight requests with `HostCrashed`;
     - restarts the host.
   - Kills the whole process tree, including on Windows.
   - Per-language `[ParallelLimiter]` from `maxConcurrency`.
   - Keeps a per-test control transcript (the last 500 messages) attached as a TUnit artifact on failure.
3. **Leak audit.** An `[After(Test)]` hook calls `EndTestAuditAsync`; any leak fails the test.
4. **Retry policy.** A narrow attribute that retries only on `HostCrashed`, at most once.
5. **Host launch config.** Comes from `artifacts/interop/<lang>/host.json`, written by the J12/K12 builds, with the command, args and working dir. If the file is missing, rows for that language fail with the build command to run.
