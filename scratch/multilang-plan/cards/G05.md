# G05 — Hash parity tests (IR constants vs compiled C# client)

| Size | Lands on | Requires | Branch |
|---|---|---|---|
| S | train | G03 | `mt/G05-hash-parity` |

## Goal
Prove that the handshake constants emitted for foreign targets equal what a real C# client computes for the same interface pair.

## Owns
- `src/NexNet.Generator.Tests/HashParity/**` (new)

## Steps
1. For a set of fixture interface pairs (plain, versioned, with collections, with pipes and channels, with unions), compile in-memory:
   - a C# client nexus;
   - a server class with `Targets` set.
2. Assert that the IR export's fields equal the compiled client's runtime values, read through the test-only internals:
   - `Handshake.ClientNexusHash` and `ServerNexusHash`;
   - `Version`;
   - `ClientAcceptedIds`.

   The runtime values are `MethodHash` and `VersionHashTable`, plus `VersionMethodHashSet`.
3. Add a fixture for the V1 export via `NexusClientExport`.

## Verify
`dotnet test src/NexNet.Generator.Tests -c Release`
