| Size | Lands on | Requires | Branch |

Read `cards/P01-shared.md` first.

## Goal
Pick about 20 server-focused tests where a foreign client's wire behavior matters, and give them a `[CrossLanguageSmoke]` client matrix. The rest of bucket B stays C#-only.

## Candidates
- **Group and All broadcasts:** `NexusServerTests_NexusGroupInvocations`, `_NexusInvocations`.
- **Multi-endpoint broadcast reach:** a mixed-language client set across HttpSocketTls and WSS (S02).
- **Rate limiting:** a foreign client sees a clean rejection.
- **Version validation:** a mismatched hash disconnects with the right reason.
- **Session lifetime:** `NexusServerTests_InvocationLifetime`.
- **Separate pool:** a `SeparatePool` method invoked from each client.
- **Client-side protocol hardening:** use the H02 frame-injection hook to feed malformed server frames to each language. Each must disconnect with ProtocolError, not crash.

- The list is documented in the PR.
- Green on all available rows.
