## Steps
1. **Public API:**

   ```csharp
   server.AddListener(ServerConfig config, string name);                          // listener-mode configs only
   IAcceptsExternalTransport server.AddExternalEndpoint(ServerConfig config, string name);
   IReadOnlyList<NexusEndpointInfo> server.Endpoints { get; }
   ```

   - Both `Add*` calls are only allowed before Start. There is no hot add in v1.
   - Validate at `Add*` time: duplicate names, ports, paths and UDS paths are rejected.
   - A secondary config must not set a different `Time` or a non-null `RateLimiting`.
2. **Which settings come from where:**

   | Scope | Settings |
   |---|---|
   | Server-wide (primary config only) | Logger, Time, MeterFactory, RateLimiting, MaxPendingHandshakes, session manager, watchdog period, collections |
   | Per endpoint (the endpoint's config becomes the session's `Configs`) | all session settings in `ConfigBase`, including `Timeout`, `HandshakeTimeout`, `MaxMessageSize` and flow control; `Authenticate`; `AuthorizationCacheDuration`; TLS and socket options; ASP path, auth and proxy headers; `TransportName` |

   Run `ValidateFlowControl` per endpoint. The watchdog uses each session's own `Timeout`, ticking at min(Timeout)/4.
3. **Security guard.** Start throws if the primary requires `Authenticate` but any endpoint does not.
4. **Metrics and logs:**
   - one `MetricsTagSet` per endpoint, plus a low-cardinality `nexnet.endpoint` tag;
   - a child logger named `SV{id}/{name}`;
   - `NexusServerSnapshot.Endpoints[]` with name, transport, state, address and session count.
5. **`Context.Endpoint`.** Expose `NexusEndpointInfo(string Name, string Transport, bool IsSecure, string? Path)` on the session context.
   - It is available from `OnAuthenticate` onward.
   - For ASP endpoints, `IsSecure` comes from `Request.IsHttps` at accept time.
6. **NexNet.Asp:**
   - Add `MapNexusWebSocket(server, cfg)` and `MapNexusHttpSocket(server, cfg)`, which route through `AddExternalEndpoint`.
   - The existing `Map*(cfg, server)` calls also route through it. If `cfg` is the primary config, keep today's exact behavior.
   - The `Use*NexusServerAsync` helpers configure the server, or attach if it is already configured, instead of throwing.
   - Add `AddNexusServer(o => { o.Configure(primary); o.AddListener(tcp, "tcp"); })` and a hosted lifecycle service: StartAsync runs on `ApplicationStarted` (after Kestrel binds), StopAsync on `ApplicationStopping`.
   - Remove the `Unsafe.As` call sites.
7. **Tests.** One server exposing TCP, UDS, HttpSocket and WS at once:
   - `All`/`Group` broadcasts, collections and `ContextProvider` reach clients on every transport;
   - per-endpoint `MaxMessageSize`, `Authenticate` and `Timeout` are honored;
   - each endpoint has its own metric tags;
   - a bind failure on the 2nd endpoint rolls everything back;
   - per-IP rate limits span transports;
   - the hosted service stops TCP sessions;
   - `Context.Endpoint` is correct on every transport.

## Acceptance
- The existing `CreateServer(config, factory)` path is behaviorally identical.
- The release note states the one behavior change: `Map*` with a non-primary config now applies that config's session settings.
