# K06 — Java transports: HttpSocket, RFC 6455 WSS, TCP, TcpTls

| Size | Lands on | Requires | Branch | Decision |
|---|---|---|---|---|
| M | train | K05, F09c | `mt/K06-java-transports` | D4 (no UDS) |

## Owns
- `clients/java/nexnet-client/src/main/java/com/dtronix/nexnet/transport/**`, except `Transport.java`
- tests

## Steps
1. **TLS factory.** Builds an `SSLContext` from the config:
   - system trust plus an optional custom CA (PEM or KeyStore);
   - an optional SPKI sha256 pin, via a wrapping `X509TrustManager`;
   - an optional client certificate via a `KeyManager` (PKCS#12).
   - **Hostname verification always on:** `SSLParameters.setEndpointIdentificationAlgorithm("HTTPS")`. Plus an explicit `HostnameVerifier` check after the handshake, for Android compatibility.
   - SNI via `setServerNames`.
   - **No ALPN.** `setApplicationProtocols` is API 29, and HTTP/1.1 is implied.
2. **TCP / TcpTls.** `Socket` / `SSLSocket` with a connect timeout and `TCP_NODELAY`.
3. **HttpSocket over TLS or plain.** A hand-written HTTP/1.1 upgrade:
   - `Host` includes the port when it is non-default;
   - `Connection: Upgrade` and `Upgrade: nexnet-httpsockets`;
   - optional `Authorization` and the query token.

   Parse the response with a CRLF parser capped at 16 KiB. **Bytes read after `\r\n\r\n` seed the session input.** 401/403 map to an auth error.
4. **RFC 6455 WS/WSS client**, about 500 lines, over the same socket and TLS stack:
   - the key/accept SHA-1 check, via `MessageDigest`;
   - client masking with `SecureRandom`;
   - fragmentation;
   - ping/pong;
   - the close handshake;
   - binary only, no subprotocol;
   - incoming messages concatenated into a byte stream.

   Avoid `java.util.Base64`, which is API 26; ship a tiny Base64 encoder.
5. **Remote certificate.** From the `SSLSession`.
6. **Tests.** Use a local JDK test server (`com.sun.net.httpserver` is not suitable for upgrades; write a minimal socket server in the test sources) for:
   - upgrade edge cases;
   - fragmented WS frames;
   - a pin mismatch;
   - a hostname mismatch rejected.

## Verify
`gradlew check`. Animal Sniffer must pass.
