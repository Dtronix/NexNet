## API shape
- `NexusList<T>` implements a read-only `java.util.List<T>` view. Mutators on that view throw `UnsupportedOperationException`.
- Async mutation methods return `CompletableFuture<Boolean>`: `addAsync`, `insertAsync`, `removeAsync(item)`, `removeAtAsync`, `replaceAsync`, `moveAsync`, `clearAsync`.
- `enable()`, `disable()`, `ready()`, `disabled()`, `state()`.
- `addChangeListener(Consumer<NexusListChange<T>>)`. Listeners are delivered on the callback executor.

## Rules
- `removeAsync(item)` uses `equals`, generated for structs and records (K03).
- Versioned apply, reset buffering, stale-op drop, Ack/Noop, and one op in flight at a time.
- No automatic resume after reconnect.
