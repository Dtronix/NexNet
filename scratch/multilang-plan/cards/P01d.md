## Notes
- **Versioning tests** need the generator to emit a client export per interface version. Use `[assembly: NexusClientExport<IServerV1, IClient>]` in TestNexus, and select the export via `ClientSpec.Export`.
- **TLS tests:**
  - require `Capability.ClientCertificate`, `Pinning` and `CustomCa` as appropriate;
  - use the F08 certificates and SPKI pin;
  - the browser rows are skipped, with the reason shown.
- **Authorization-header tests** require `Capability.AuthorizationHeader`.
- **Add query-token variants (F06)** that also run on the browser rows.
- **Add a greeting-token test** that runs on every row (the canonical auth path, D15).
