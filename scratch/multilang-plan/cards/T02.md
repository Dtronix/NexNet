## Owns
- `src/NexNet.Generator.Tests/**`
- `src/Directory.Build.props` (**hot**): only if a central TUnit version is added
- **Pin the TUnit version** in one place, a version at least two weeks old (D-note in `01-context.md` §7)

## Steps
1. Swap the packages: remove NUnit, NUnit.Analyzers and the NUnit MTP runner; add pinned `TUnit`. Check that restore is clean under the NuGet audit.
2. Run the TUNU0001 code fixer:

   ```
   dotnet format analyzers src/NexNet.Generator.Tests --severity info --diagnostics TUNU0001
   ```
3. Fix the leftovers by hand:
   - make methods with asserts `async Task`;
   - await every assert;
   - make `AssertWalk` and its callers async.
4. Keep the engine in **source-gen mode**; reflection mode drops internal tests.
5. Make sure TUnit's generated code compiles warning-free under `Nullable` and `EnablePreviewFeatures`.

## Acceptance
- The test count is the same as before (190).
- The suite is green, including in parallel (this suite is in-memory and parallel-safe).
