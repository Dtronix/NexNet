## Steps
Write one subsection per gap, citing the source file for each.

- **G1 Ping roles.** The client pings, the server replies, and the idle timeout is local to each side. Add a forward note that S04 adds `idleTimeoutMs`.
- **G2 Handshake validation.** Every check and the disconnect reason it produces (`NexusSession.Receiving.cs` MessageHandler, `NexusSession.cs:93-95`). State that hashes are opaque generator constants, and that up to 3 greeting attempts are allowed.
- **G3 Greetings 100 vs 101.** Document current behavior: the server treats 101 like 100.
- **G4 Auth token.** The token is `bin` or `nil`; senders send an empty `bin`.
- **G5 Incoming method-ID validation.** Calls are checked against `(versionHash<<16 | methodId)`.
- **G6 Disconnect frames.** No body. Unknown codes 20–38 are still disconnects. The sender waits `DisconnectDelay`; the receiver does not reply.
- **G7 Pipe, channel and collection methods.** They are sent with `IgnoreReturn|DuplexPipe`. Describe the authorization-refusal outcome per F04 if it has merged, otherwise current behavior.
- **G8 Pipe ID allocation.** IDs are 1..255 and 0 means unassigned. A partial ID has peer byte 0, and a refusal carries the opener's partial ID.
- **G9 Large-message thresholds.** Arguments larger than 65,526 bytes are streamed. Chunks are at most 65,535 bytes. Any `totalLength` up to the max is valid.
- **G12 Exact bit layouts** (source: `src/NexNet/Serialization/PrimitiveFormatters.cs`):
  - `DateTime` `ToBinary`: tick epoch 0001-01-01, 100 ns ticks, kind in bits 62–63, and the Local encoding including the DST-ambiguity bit;
  - `TimeSpan` ticks, `DateOnly` DayNumber, `TimeOnly` ticks;
  - `decimal` as lo/mid/hi/flags, with scale in bits 16–23 and sign in bit 31;
  - `Guid` byte order;
  - `Half` and `char`.
- **G13 `InvocationCredit{0}`.** It causes a FlowControl disconnect.
- **G14 Client-side pre-auth rule.** It is symmetric with the server's.
- **G15 Caller-side cancellation.**
  - A cancel before send completes as canceled (D17/F03).
  - A cancel after send completes as canceled immediately, and the late result is still consumed.
