## Notes
- **`ConnectsToServer` and connect-hook tests** use `OnConnected` script events. Do not use `InternalOnClientConnect`; H01 removed it.
- **Ping and timeout tests** need `Capability.FakeTime`. They use `AdvanceTimeAsync`, and the host's injectable clock must drive the ping timer.
- **`ClientTimesOutWithNoServer`** (ConnectionTimeout = 50 ms) must use `T(x)` and host-measured durations.
- **Reconnect tests** stop and restart a dedicated server instance. Do not use the shared host for them.
