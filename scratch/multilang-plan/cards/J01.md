## The contract (skeleton only)
1. **Codec:**
   - `MsgPackWriter` and `MsgPackReader`;
   - `Formatter<T>` = `{ write(w, v), read(r) }`;
   - `FormatterRegistry`.
2. **Value types:** `NexusDecimal`, `NexusDateTime`, `NexusDateTimeOffset`, `NexusTimeSpan`, `NexusDateOnly`, `NexusTimeOnly`, `NexusVersion`, `Tuple` helpers.
3. **Session-facing API for generated code:**
   - `NexusClient` with `create(config, nexus)`, `connect`, `tryConnect`, `disconnect`, `state`, `disconnected`, `proxy` and `Symbol.asyncDispose`;
   - `ClientConfig` with typed transport configs (`webSocket`, `httpSocket`, `tcp`, `tcpTls`, `uds`);
   - `ProxyBase` with `_invoke(methodId, args, {signal, returns: formatter})`, `_invokeVoid`, `_invokePipe` and `_invokeChannel`;
   - `ClientNexusBase` with `onConnected(isReconnected)`, `onDisconnected`, `onReconnecting`, `context`, and the dispatch hook `_dispatch(methodId, reader, ctx)`;
   - `NexusDuplexPipe`, `NexusChannelReader` and `NexusChannelWriter`;
   - `NexusList`;
   - `NexusClientPool`;
   - `CancellationError` mapping (`AbortError`);
   - the error classes `NexusTransportError`, `NexusRemoteInvocationError`, `NexusUnauthorizedError`, `NexusBusyError` and `NexusMessageTooLargeError`.
4. **Handshake descriptor** that generated code passes to the runtime: `{ version, serverNexusHash, clientNexusHash, acceptedIds: BigUint64Array|Set<number> }`.

## Rules
- **Browser entry purity.** The `browser` entry must never import `node:*`. Add a test that bundles the browser entry and fails on `node:` imports, using a simple static import-graph check.
- **Zero runtime dependencies.** Dev dependencies are `vitest`, `@vitest/browser`, `playwright`, `typescript` and `eslint`, at pinned versions at least two weeks old.
