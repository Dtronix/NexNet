## Steps
1. **`MsgPackWriter`:**
   - a growable `Uint8Array` with a `DataView`;
   - canonical smallest encoding (spec §10.1);
   - `bigint` paths for 64-bit values;
   - float32 vs float64 chosen by the declared type;
   - str8/16/32 encoding, using `TextEncoder` for strings at or above ~32 bytes and a manual loop below that;
   - bin, arrays, maps;
   - ext 78 primitive arrays: little-endian, with a copy for alignment.
2. **`MsgPackReader`:**
   - a cursor over `Uint8Array` segments;
   - hardening per `NexusSerializerOptions`: MaxDepth, MaxElements, StrictUtf8 via `TextDecoder('utf-8',{fatal:true})`, and the Untrusted/Trusted presets;
   - decoding of nil, bool, ints (number or bigint, by the requested kind), floats, str, bin, array/map headers and skip.
3. **Built-in formatters** for every spec §10.4 type, following the mapping in `01-context.md` §5. Range checks apply on write. `long`/`ulong` use `bigint`; add an opt-in `checkedNumber` variant for D13.
4. **Value types,** with exact round-trip:
   - `NexusDecimal`: 96-bit magnitude, scale and sign; `toString` and `parse` via bigint; `toNumber`.
   - `NexusDateTime`: bigint ticks plus kind, including the Local encoding bits; `toDate()` and `fromDate()`.
   - `NexusTimeSpan`, `NexusDateOnly`, `NexusTimeOnly`, `NexusDateTimeOffset`.
   - `Guid` as a lowercase string, with byte-order conversion.
   - `Half` via `Math.f16round` or a fallback.
   - `char` as a 1-char string.
5. **Golden tests.** A Vitest `test.each` over `tests/golden/*.jsonl`, located from the repo root (`../../../tests/golden`), exercising all three modes. The same suite runs in browser mode with the files bundled via `import.meta.glob`.
6. **Micro-benchmarks** (Vitest `bench`) for the int64, string and ext 78 paths.

## Acceptance
- 100% of the golden vectors pass in Node and Chromium.
- No runtime dependencies.
