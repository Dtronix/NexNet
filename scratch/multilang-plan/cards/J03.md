# J03 — Generator: JS formatter emitter (+ .d.ts)

| Size | Lands on | Requires | Unblocks | Branch |
|---|---|---|---|---|
| L | train | J02, G04 | J04 | `mt/J03-js-formatter-emitter` |

## Owns
- `src/NexNet.Generator/Targets/JavaScript/**`, except the files J04 and J11 create (`ProxyEmitter.cs`, `ScaffoldingEmitter.cs`)
- `src/NexNet.Generator.Tests/Targets/JavaScript/**`

## Steps
1. **Types module.** For every `TypeDeclIr` reachable from a JS export, emit `<module>/types.js` and `types.d.ts`:
   - `[NexusObject]` classes have a `constructor(init)` and JSDoc. In `.d.ts`, members are typed per the mapping, and nullable members are `T | null`.
   - **Enums** become a frozen constants object plus a literal union type. 64-bit enums use bigint.
   - **Unions** are an abstract base class (or a marker for interface unions) with case classes, and a TS union type alias.
   - **Generics** use formatter factories, e.g. `boxFormatter(tFormatter)`.
   - Structural `equals(a, b)` and `hashKey` helpers for types used as `Remove(item)` operands and set/map keys (NEXNET046 already warns for reference keys).
2. **Formatters module.** `<module>/formatters.js`:
   - one `Formatter` per type: a port of `EmitObject` (array of `ArrayLength`, nil gaps, extra elements skipped, defaults from the IR `DefaultLiteral` where present) and of `EmitUnion` (write dispatches by `instanceof` in inheritance-depth order; read switches on the tag);
   - struct-typed values throw on null.
3. **Target formatters (D12).** For `NexusTargetFormatter` mappings, emit `import { X } from '<user module path>'` and reference that class. Also emit `<module>/user-formatters.d.ts`, declaring the interface the user's formatter must satisfy.
4. **Determinism.** Output is deterministic, with the header comment `// <auto-generated> NexNet <version>`.
5. **Tests:**
   - text snapshot tests (no SDK needed);
   - plus compile and run checks, which are **skipped** with a reason when `node`/`tsc` are missing and required under `NEXNET_REQUIRE_SDKS=1`:
     - emit for the interop zoo into a temp dir;
     - run `tsc --noEmit` on the `.d.ts`;
     - run a Node script that round-trips the zoo values through the generated formatters and compares them with the C#-written bytes.
