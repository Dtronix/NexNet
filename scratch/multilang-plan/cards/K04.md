## Emitted per export
1. **`<Export>Handshake`.** A `HandshakeDescriptor` constant built from the IR.
2. **`<Server>Proxy extends ProxyBase`.** One method per server method:
   - `void` → `void m(...)`;
   - `ValueTask` → `CompletableFuture<Void>`;
   - `ValueTask<T>` → `CompletableFuture<T>`, with boxed types.

   When the C# method has a `CancellationToken`, emit **two overloads**: with and without the token. The returned future's `cancel(true)` triggers a remote cancel; implement this with a `CompletableFuture` subclass.

   Pipe and channel methods take `NexusDuplexPipe` / `NexusChannelWriter<T>`. Collections are exposed as `NexusList<T>` accessors.
3. **`<Client>NexusBase extends ClientNexusBase`.** Abstract methods returning `CompletableFuture<…>` or `void`, plus a generated `dispatch` switch. It honors `SeparatePool` and maps the inbound cancellation token.
4. **Factory.** `<Export>Client.create(ClientConfig, nexus)`.
5. **Javadoc** copied from the C# XML docs.
